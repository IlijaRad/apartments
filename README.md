# Green Olive Studio Apartments

A TypeScript, Tailwind CSS and Next.js App Router site for Green Olive Studio Apartments in Cavtat, Croatia.

## Development

- `npm install`
- `npm run dev`
- `npm run lint`
- `npm run build`

The site is a static marketing/contact page. Reservation availability and rates are requested by phone or email; no booking backend or channel calendar is configured. Vercel supplies the deployment URL for absolute Open Graph URLs.
